# AKMAVREN · коммерческие демосайты

Статическое портфолио на GitHub Pages. QYR показывает путь клиента барбершопа и работу владельца в CRM. Sary Coffee, Forma и Qadam Fit доступны по прежним адресам.

## Витрина проектов

На [главной](./) можно переключать предпросмотры четырёх сайтов касанием, мышью или стрелками клавиатуры. Список проектов открывает меню, галерею, расписание и запись прямо в окне витрины. QYR CRM открывается из отдельного раздела. Кнопка «Открыть отдельно» ведёт на обычную страницу, а при выключенном JavaScript ссылки работают напрямую. Системная настройка уменьшенного движения отключает анимации.

## Открыть QYR

| Экран | Русский | Қазақша |
| --- | --- | --- |
| Сайт и пробная запись | [Сайт](demos/qyr/) | [Сайт](kk/demos/qyr/) |
| Владелец | [CRM](demos/qyr/admin/#dashboard) | [CRM](kk/demos/qyr/admin/#dashboard) |
| Мастер | [Календарь](demos/qyr/admin/?mode=master#calendar) | [Күнтізбе](kk/demos/qyr/admin/?mode=master#calendar) |

На сайте выберите услугу или мастера и пройдите запись с вымышленным профилем. Через «Мои записи» откройте детали, подтвердите визит, перенесите или отмените его по правилам, сообщите об опоздании рядом с временем визита или скачайте ICS.

В CRM откройте будущую запись, чтобы проверить перенос и отмену. На ближайшем визите доступны отметки прибытия, начала и завершения. Выручка увеличивается при завершении с отметкой пробной оплаты. Услуги, цены, доступность мастеров и опубликованные тексты отражаются на сайте в том же браузере. Предпросмотр сайта можно открыть до сохранения.

Переключатель «Мастер» открывает расписание выбранного сотрудника и действия с его визитами. Сценарий знакомства с CRM можно пропустить, а затем запустить из настроек.

## Данные и правила

- Календарь использует `Asia/Almaty`. Начальное расписание строится относительно текущей даты. Доступность учитывает совместимость услуг, назначенных мастеров, сетку старта, графики, буфер, перерывы, отпуска, блокировки, активные записи и временные резервы.
- Выбор даты показывает только дни со свободными интервалами для выбранных услуг и мастера. Фильтр Qadam Fit показывает только дни с тренировками.
- Цена, состав услуг и продолжительность фиксируются при создании записи. Перенос проверяет новый интервал перед заменой и сохраняет исходную цену. Деактивация мастера сохраняет его историю и предлагает отменить будущие записи или перенести их вручную.
- Для подтверждения телефона используется код `0000`. Предоплата отмечается как имитация. Администратор может включить ручную проверку после повторных неявок и автоматическую отмену неподтверждённых записей. Интервалы подтверждённых визитов сохраняются при опоздании до решения владельца.
- В центре уведомлений показываются примеры WhatsApp. Напоминания и освобождение истёкших резервов обрабатываются в открытых вкладках и при следующем посещении. Демонстрация никогда не отправляет сообщения.
- Финансы считают полученной выручкой только оплаченные завершённые визиты. Ожидаемая сумма складывается из открытых записей за выбранный период. Отчёт в CSV содержит записи, расходы и итоги.
- Данные хранятся в `localStorage` под ключом `akmavren-qyr-v2`, сохраняются после обновления и синхронизируются между вкладками одного origin. При наличии Web Locks каждое изменение повторно проверяется под общей блокировкой. Старые записи QYR импортируются один раз. Повреждённая версия восстанавливается из начального демонабора. Полный сброс удаляет локальные изменения.
- Используйте только демонстрационные имена и тексты. Клиентские профили предустановлены, свободного ввода телефона нет. Контактный email принимает только домен `.example`. Для фотографий доступна локальная коллекция. У приложения нет защищённой авторизации, интеграций SMS или оплаты. Для настоящего бронирования, многопользовательской синхронизации и доставки нужен сервер.

## Локальная проверка и публикация

Для проверок нужны Node.js 22 или новее и Chromium. GitHub Pages по-прежнему публикует статические файлы из корня основной ветки с `.nojekyll`. Путь сайта — `/portfolioakm.github.io/`. Сервер и npm для публикации не требуются. Сборка ниже копирует статические файлы в `dist/` и проверяет синтаксис модулей. Это локальный артефакт для проверки перед обновлением публикации.

```sh
npm ci
npx playwright install chromium
npm test
npm run build
npm run test:browser
```

Чтобы использовать системный Chromium, передайте `CHROMIUM_PATH=/путь/к/chromium`. Браузерный тест запускает локальную копию `dist/` под базовым путём GitHub Pages, проверяет прямые ссылки, сценарии записи и CRM, оба языка и ширины 360, 390, 430, 768, 1024 и 1440 px. Скриншоты сохраняются в `test-results/`.

Чтобы открыть локальную сборку вручную с корня, используйте `python -m http.server --directory dist 8000` и перейдите на `http://localhost:8000/demos/qyr/`. Для проверки абсолютных ссылок страницы 404 используйте сервер в браузерном тесте, который выдаёт сайт с префиксом публикации.
