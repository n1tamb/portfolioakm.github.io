О проекте

Это демосайт для портфолио. Ниже описано, какую задачу он показывает и что понадобится для настоящего бизнеса.

Задача

Посетитель хочет быстро найти удобную тренировку и записаться.

Что сделано

  • Расписание на неделю с фильтром по дням
  • Уровень и длительность каждого занятия
  • Пробная запись и отмена прямо из расписания
  • Готовый текст записи для WhatsApp

Для настоящего бизнеса

  • Общая база записей и лимит мест на занятии
  • Расписание с датами, которое может менять администратор
  • Контакты клиента с согласием на обработку данных и напоминания
